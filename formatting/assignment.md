# Assignments

Follow the [[README|general formatting standard]]. Homework, quizzes, discussion
worksheets, and written activities use named files in their category directory.
Use the shared question and answer format when solutions are available.

Code projects and assignments with a required working directory keep that layout:

```text
p05/
├── README.md          # assignment specification
├── notes.md           # optional student notes
├── assets/            # figures
└── (required code and data)
```

- Keep the assignment specification faithful to its requirements. Student code,
  personal submissions, reflections, and solution notes remain distinct from it.
- Preserve runnable worksheets, datasets, required filenames, and starter code.
- Link assignments to the relevant lectures and from their category hub or
  course README.
