# Import course content

Read `formatting/README.md`, then the relevant content-type spec. For binaries,
also follow `formatting/conversion.md`.

1. Merge supplied material with existing notes on the same content. Preserve
   substantive source content, personal work, and required course files. Review
   changed equations, questions, choices, and diagrams against the source.
2. File single documents as named Markdown files. Use `index.md` for collection
   hubs. Apply the shared question and answer format where appropriate.
3. Add verified wikilinks to related material and an incoming link from its hub
   or the course README. Update all references when moving or merging files.
4. Keep citations and specific unresolved ambiguities brief. Keep importer
   narration, source filenames, and processing reports out of filed notes.

Return the filed content and a brief completion report to the user. Report
remaining source gaps or validation limits there; processing details belong in
private review reports. Follow the general standard's exceptions for required
filenames, source attribution, and substantive caveats.
